# 3주차. 연산자와 입출력

> 단계: 기초 | 선수: 2주차 (변수, 자료형, 형 변환)

## 학습 목표
- 산술·비교·논리 연산자를 사용한다
- `input()` 으로 사용자 입력을 받는다
- `print()` 와 f-string으로 보기 좋게 출력한다
- 입력받은 문자열을 숫자로 변환해 계산한다

## 1. 산술 연산자

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `+` | 더하기 | `5 + 3` | `8` |
| `-` | 빼기 | `5 - 3` | `2` |
| `*` | 곱하기 | `5 * 3` | `15` |
| `/` | 나누기 (실수) | `7 / 2` | `3.5` |
| `//` | 나누기 (몫) | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 10` | `1024` |

## 2. 비교 연산자와 논리 연산자

```python
print(5 > 3)            # True
print(5 == 5)           # True (같다)
print(5 != 3)           # True (다르다)

print(True and False)   # False
print(True or False)    # True
print(not True)         # False
```

## 3. 대입 연산자

```python
x = 10
x += 5    # x = x + 5  →  15
x -= 3    # 12
x *= 2    # 24
x //= 5   # 4
```

## 4. input() 으로 입력 받기

```python
name = input("이름을 입력하세요: ")
print("환영합니다,", name)
```

⚠️ `input()` 은 **항상 문자열**을 반환합니다. 숫자를 받으려면 형 변환:
```python
age = int(input("나이: "))
```

## 5. f-string 으로 포맷팅

```python
name = "홍길동"
score = 95
print(f"{name}님의 점수는 {score}점입니다")

# 자릿수 / 소수점 / 정렬
price = 12345
print(f"가격: {price:,}원")        # 가격: 12,345원
print(f"원주율: {3.141592:.2f}")    # 원주율: 3.14
print(f"{name:>10}")                # 우측 정렬 폭 10
```

## ⚠️ 자주 하는 실수

1. **`input()` 결과를 그대로 계산**
   ```python
   a = input("수: ")   # 문자열
   print(a + 10)       # TypeError
   ```
   → `a = int(input("수: "))`

2. **`/` 와 `//` 혼동**
   `/` 는 항상 실수, `//` 는 몫(정수). `5/2 = 2.5`, `5//2 = 2`.

3. **f-string 앞에 `f` 빠뜨림**
   ```python
   print("{name}님")   # 그냥 "{name}님" 출력
   print(f"{name}님")  # 변수 치환됨
   ```

4. **`==` 대신 `=` 사용**
   `=` 은 할당, `==` 은 비교. 조건문에서 자주 헷갈림.

## ❓ FAQ

**Q1. `print()` 끝에 줄바꿈이 자동으로 들어가는데 안 되게 하려면?**
A. `print("hi", end="")` 로 줄바꿈 제거. `end="-"` 처럼 다른 문자도 가능.

**Q2. 여러 변수를 한 번에 출력하려면?**
A. `print(a, b, c)` 처럼 콤마로 구분하면 공백으로 연결. `sep="-"` 로 구분자 변경 가능.

**Q3. 입력을 한 줄에 여러 개 받으려면?**
A. `a, b = input("두 수: ").split()` — 공백으로 분리. 여전히 문자열이므로 형 변환 필요.
