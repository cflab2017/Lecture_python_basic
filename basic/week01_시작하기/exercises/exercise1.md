# 과제 1. 환경 설치 인증

## 목표
파이썬과 VS Code를 정상 설치했음을 확인한다.

## 요구사항
1. 터미널에서 다음 명령으로 파이썬 버전 확인:
   ```bash
   python --version
   ```
2. VS Code를 실행하고 Python 확장(Microsoft) 설치
3. 다음 두 가지 스크린샷 제출:
   - 터미널의 `python --version` 결과
   - VS Code에서 `print("Hello")` 작성 후 실행한 화면

## 채점
- 파이썬 3.10 이상 설치 — 50%
- VS Code에서 코드 실행 성공 — 50%
