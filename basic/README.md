## 각 주차 폴더 구조

```
weekNN_주제/
├── README.md       수업 노트 (학습목표, 개념 설명, FAQ, 자주 하는 실수)
├── examples/       수업 예제 (.py — 그대로 실행 가능)
├── exercises/      과제 명세 (.md) + 시작 코드 (.py)
└── solutions/      과제 해답 (.py)
```

## 학습 순서

1. `weekNN/README.md` 정독
2. `examples/` 의 코드를 직접 타이핑하며 실행
3. `exercises/` 의 과제를 본인 힘으로 작성 (해답 보지 말 것)
4. 막힐 때만 `solutions/` 참고
5. 다음 주차로 이동
