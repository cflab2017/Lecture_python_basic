# 과제 1. 가위바위보 (확장판)

> 난이도: Lv ★ | 사전지식: 기초 4-5주차 (조건문, 반복문, random)

## 목표
사용자 vs 컴퓨터 가위바위보 — 3판 2선승, 통산 전적 누적

## 기초 과제와의 차별점
- **기초 4주차** = 1회 결과 출력 후 종료
- **여기** = 3판 2선승 + 무한 루프 + 잘못된 입력 재요청 + 통산 전적 누적

## 요구사항
- 입력: `가위`, `바위`, `보` (한글 또는 `r/p/s`)
- 컴퓨터는 `random.choice`
- 매 라운드마다 결과 출력 (승/패/무, 현재 스코어)
- 3승 먼저 달성한 쪽이 매치 승자
- 매치 후 "한 게임 더?" 물어보기
- 통산 전적(승/패/무) 누적

## 입출력 예시
```
[1라운드] 선택(가위/바위/보): 가위
컴퓨터: 보  → 사용자 승!  (1 : 0)

[2라운드] 선택: 바위
컴퓨터: 바위 → 무승부 (1 : 0)

...

🏆 매치 승자: 사용자 (3:1)

한 게임 더? (y/n): n

[통산 전적]  사용자 1 매치, 0 매치, 0 무
```

## 도전 과제
- 컴퓨터가 사용자 패턴을 학습 (마지막 3개 입력 보고 다음 예측)
- 통산 전적을 파일로 저장
