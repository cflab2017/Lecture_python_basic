# 과제 6. 단어장 퀴즈 (확장판)

> 난이도: Lv ★★ | 사전지식: 기초 7-8주차 + random

## 목표
영-한 사전으로 랜덤 퀴즈 + 양방향 모드 + 복습 모드

## 기초 과제와의 차별점
- **기초 종합 예시** = 단순 출제 + 점수
- **여기** = 양방향 + 복습 모드 + 통계

## 요구사항
- 단어장 딕셔너리 (10개+)
- 모드 선택: 영→한 / 한→영 / 랜덤
- 10문제 출제, 즉시 피드백
- 마지막에 점수 + 틀린 단어 + 복습 옵션

## 도전 과제
- 단어장 외부 파일 로드
- 정답률 단어별 누적
