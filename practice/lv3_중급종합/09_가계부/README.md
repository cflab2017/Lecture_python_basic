# 과제 9. 가계부

> 난이도: Lv ★★★ | 사전지식: 중급 5-6주차 (예외, JSON I/O)

## 목표
수입/지출을 JSON 파일에 영구 저장하는 가계부

## 요구사항
- 파일: `ledger.json` (종료 후 데이터 보존)
- 명령: `add 수입|지출 금액 카테고리 메모`, `list`, `summary`, `del <번호>`
- 카테고리별 합계, 잔액
- 잘못된 입력은 예외 처리

## 도전 과제
- 월별 집계 (`2026-05` 필터)
- 카테고리별 막대그래프 (`#`)
- 한 줄 명령 (`add 지출 5000 식비 점심`)
