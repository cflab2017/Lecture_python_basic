# 과제 2. groupby 로 로그 날짜별 그룹

## 목표
로그 라인을 날짜별로 묶어 출력.

## 입력
```
2026-05-09 10:00 INFO 시작
2026-05-09 10:05 ERROR 에러
2026-05-10 09:00 INFO 시작
2026-05-10 11:00 INFO 정상
```

## 출력
```
[2026-05-09]
  10:00 INFO 시작
  10:05 ERROR 에러
[2026-05-10]
  09:00 INFO 시작
  11:00 INFO 정상
```

## 힌트
itertools.groupby(lines, key=날짜추출함수)
